## Обзор мировых паттернов

Прежде чем предлагать варианты — анализ лучших практик для задачи «список элементов → вложенная конфигурация».

### Паттерн 1: Slide-out Drawer (выезжающая панель)

**Где используется:** Jira (issue detail), Notion (page properties), Linear (issue panel), Salesforce, HubSpot

**Суть:** Основной список слева. Клик по элементу → справа выезжает панель поверх контента (не сдвигает список). Панель можно закрыть (✕) или кликнуть мимо.

**Плюсы:** Экономия места, контекст списка сохраняется, привычно для веб-админок.
**Минусы:** Нельзя видеть два элемента одновременно, панель перекрывает часть списка.

### Паттерн 2: Expandable Rows (раскрывающиеся строки)

**Где используется:** Datadog (monitors), Airtable (expanded records), Monday.com, AWS CloudWatch

**Суть:** Каждая строка таблицы имеет кнопку раскрытия (chevron ▼). При клике под строкой появляется вложенная область с деталями. Можно раскрыть несколько строк одновременно.

**Плюсы:** Контекст строки сохраняется идеально, можно сравнивать несколько раскрытых строк, не нужно никуда кликать для беглого просмотра.
**Минусы:** Таблица может стать очень длинной, скролл может быть неудобным.

### Паттерн 3: Persistent Split View (постоянная мастер-деталь)

**Где используется:** macOS Finder (column view), Apple Mail (3-column), VS Code (sidebar + editor), Azure Portal, Figma (layers + properties)

**Суть:** Экран постоянно разделён на две (или три) панели. Слева — список, справа — всегда видимые детали выбранного элемента. При выборе другого элемента детали обновляются справа.

**Плюсы:** Всегда видно и список, и детали. Профессиональный инструментальный UX. Быстрая навигация клавиатурой (↑↓).
**Минусы:** Требует ширины экрана (мин. ~1200px), меньше места для таблицы.

### Паттерн 4: Card Grid (карточки)

**Где используется:** Stripe Dashboard, Vercel Projects, Netlify Sites, Heroku Apps

**Суть:** Элементы отображаются не таблицей, а карточками в сетке (2-3 колонки). Карточка показывает ключевую информацию. Клик → модальное окно или переход на страницу элемента.

**Плюсы:** Визуально привлекательно, хорошо для небольшого числа элементов, легко сканировать.
**Минусы:** Хуже для сравнения, меньше информационная плотность, плохо для 20+ элементов.

### Паттерн 5: Tree + Inspector (дерево + инспектор)

**Где используется:** Figma (layers panel), Webflow (navigator), Unity, Blender

**Суть:** Слева — иерархическое дерево (терминал → страницы → элементы). Справа — панель свойств выбранного узла.

**Плюсы:** Видна вся иерархия сразу, естественно для вложенных структур.
**Минусы: Обсудили на встрече — «вкладка на вкладке под вкладкой», «жесть», отвергнуто командой.**

### Матрица применимости

| Паттерн | Сканирование | Сравнение | Глубина | Компактность | Современно |
|---------|:--:|:--:|:--:|:--:|:--:|
| Slide-out Drawer | ★★★★ | ★★ | ★★★★★ | ★★★★★ | ★★★★★ |

| Persistent Split | ★★★★ | ★★★★ | ★★★★★ | ★★★ | ★★★★★ |
| Card Grid | ★★★ | ★★ | ★★★ | ★★★ | ★★★★★ |
| Tree + Inspector | ★★★ | ★★ | ★★★★★ | ★★★★ | ★★★ |

#### Механика

- Панель выезжает **поверх** контента (не сдвигает таблицу), ширина ~420-480px
- Анимация: slide-in справа, 200ms ease-out
- Полупрозрачная подложка (overlay) между таблицей и панелью — клик мимо закрывает
- Крестик ✕ вверху панели — закрыть
- Клавиша Escape — закрыть
- Строка таблицы подсвечивается (`bg-surface-selected`), пока панель открыта

#### Детали правой панели

- **Шапка:** название терминала + иконка + текущая тема с кнопкой «Сменить»
- **Странички темы:** сгруппированы в секции с заголовком (название странички)
- **Внутри странички:** список элементов (Advertise-панели / Рекомендации) с отступом
- **Каждый элемент показывает:**
  - Тип + название (иконка 📢 или 🎯)
  - Выбранную кампанию (combobox для смены)
  - Поля ID и Теги (мини-input'ы, редактируемые)
- **Скролл:** внутри панели независимый

#### Для киоска vs менюбордов

- **Киоск:** таблица = список киосков. Тема на уровне киоска. Панель = странички темы.
- **Менюборды:** таблица = список экранов (сгруппированы по серверам). У каждого экрана своя тема. Панель = странички темы экрана.

#### Плюсы
- Решает проблему визуального шума (в таблице только 3 колонки)
- Детали не загромождают основной вид
- Привычный паттерн (Jira, Notion, Linear)
- Панель можно сделать широкой — хватит места для всех полей

#### Минусы
- Нельзя видеть детали двух терминалов одновременно
- Дополнительный клик для просмотра содержимого темы
- На маленьких экранах панель может перекрыть почти всю таблицу

#### Механика

- ▶ Клик по chevron или строке → строка раскрывается, chevron поворачивается (▼)
- Раскрытая область появляется **под строкой**, растягивая таблицу
- Можно раскрыть **несколько строк одновременно** — удобно для сравнения
- Кнопка «Свернуть ▲» внизу раскрытой области
- Кнопка «Развернуть всё» / «Свернуть всё» в тулбаре таблицы
- Анимация: slide-down, 250ms ease-out

#### Дизайн раскрытой области

- Светлый фон (`bg-surface-secondary`), отличается от строки
- Лёвая граница (4px, `app-primary`) — визуально связывает с родительской строкой
- Странички — как подзаголовки с иконкой 📄
- Элементы внутри — с отступом, карточками внутри раскрытой области
- Поля ID и Теги — компактные input'ы (ширина ~100px и ~200px соответственно)

#### Кнопки управления

```
[Развернуть всё] [Свернуть всё]    — в хедере таблицы (над колонками)
```

#### Плюсы
- **Контекст не теряется** — всё в одной таблице
- Можно **сравнивать** несколько терминалов (раскрыть 2-3 строки)
- Не нужен дополнительный клик для перехода между элементами
- Привычно для инженерных/DevOps интерфейсов
- Работает на узких экранах

#### Минусы
- Таблица может стать **очень длинной** при раскрытии многих строк
- Скролл к нужной строке может быть неудобным
- При сворачивании всех строк — выглядит как обычная таблица (не видно преимуществ)

#### Механика

- Левая панель: ~360px (фиксированная или резиновая, min 320px)
- Правая панель: остаток ширины (~60-65%)
- Граница между панелями: `border-r border-border` (можно сделать перетаскиваемой — resize, но на прототипе не обязательно)
- Левая панель: список терминалов в «карточном» стиле (не таблица — чтобы не дублировать табличный подход)
  - Каждый терминал — compact card: иконка, название, тема (бейджем)
  - Выбранный терминал: `bg-surface-selected` + левая граница `border-l-4 border-l-app-primary`
- Правая панель: всегда видна, свой скролл
- Навигация: ↑↓ стрелками по левой панели, Enter — выбрать
- При первом входе: ничего не выбрано → empty state «Выберите терминал»

#### Плюсы
- **Всё видно всегда** — не надо открывать/закрывать панели
- Профессиональный «инструментальный» UX (как VS Code, Figma)
- Быстрая навигация клавиатурой
- Не перекрывает контент — детали всегда справа
- Хорошо для частого переключения между терминалами

- Меньше места для списка (левая панель уже, чем полная таблица)
- При 20+ терминалах левая панель требует активного скролла
