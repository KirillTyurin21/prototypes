## Шаг 0. Словарик (очень простыми словами)

| Слово | Что это по-человечески |
|---|---|
| **Тема** | Готовая «картинка» для рекламного экрана — как обои рабочего стола, но для менюборда |
| **Динамическая область** | «Окошко для рекламы» на этой картинке. Одно окошко = **одно рекламное место** |
| **Панель** | Раньше был вложенный уровень внутри окошка. После переделки его убрали: одно окошко = набор кампаний. Нужно больше мест — добавляем ещё одно окошко |
| **Кампания** | **ЧТО** крутится: ролик или картинки с расписанием («с 1 по 31 января, с 9 до 21 часа»). Создаётся в разделе «Кампании» |

**Запоминалка:** в области выбираются только **кампании** — ролики с расписанием. Раньше было ещё поле «Компания», но у него не оказалось источника данных, поэтому его убрали.

---

## Аналогия с кинотеатром

- Экран менюборда — это **афиша у входа в кинотеатр**.
- «Динамическая область» — **рамка на афише**, где крутится реклама. Одна рамка = одно рекламное место; нужно второе место — вешаем вторую рамку.
- Кампания — **трейлер**, который крутится по расписанию.

## 1. Как работает СЕЙЧАС

### 1.1. На боевом стенде (что есть по факту)

```mermaid
flowchart LR
    A[Администратор] --> B[Раздел «Кампании»: создаёт ролик с расписанием]
    B --> C[«Настройка терминалов»: у каждой кассы выбирает одну кампанию]
    C --> D[Касса показывает ролик]
```

- Реклама на кассе появляется так: **создали кампанию → назначили её на кассу**.
- Назначается **одна** кампания на кассу (колонка «Кампании» в таблице терминалов).
- **Компаний на стенде нет вообще** — только кампании.

### 1.2. В прототипе (текущая модель)

```mermaid
flowchart TB
    A[Открыли тему мини-борда в редакторе] --> B["Добавили элемент «Динамическая область»"]
    B --> C["Выбрали кампании: «Новогодняя», «Летнее меню»"]
    A --> D["Добавили вторую «Динамическую область»"]
    D --> E["Выбрали кампанию: «Осенние скидки»"]
    C --> F[На экране обе области крутят свою рекламу]
    E --> F
```

- **Одна «Динамическая область» = одно рекламное место**, у которого выбираются кампании.
- Нужно ещё место — добавляем ещё один элемент «Динамическая область» в тему (кнопка всегда доступна).
- Поле в инспекторе — только **«Рекламные кампании»** (мультивыбор с поиском).

## 2. Как ДОЛЖНО быть ПОСЛЕ переделки (по итогам встреч этой недели)

Что решили Михаил и Руслан на встречах **02.09** (поручение) и **08.09** (показ прототипа):

| # | Договорённость | Статус |
|---|---|---|
| 1 | Назначение рекламы — **внутри темы** мини-борда («мы должны сразу видеть, что получается» — Руслан) | ✅ Уже есть |
| 2 | Одна «Динамическая область» = одно рекламное место: набор кампаний; больше мест = больше элементов (вложенные панели убраны) | ✅ Уже есть |
| 3 | **Полноэкранное превью («глазик»):** нажал — видно «как на телевизоре»: без шахматки, без сетки, без панелей инструментов; выход по Esc. «Нажал — хоп на весь экран» (Миша) | ❌ **Ещё не сделано — это и есть оставшаяся переделка** |
| 4 | «Компании» в элементе нет — источника данных не существует (в DS-1121 компаний нет). Вопрос к Мише — отдельно | ✅ Убрано |
| 5 | Второй «лист» темы (видео на всех экранах) — **следующим этапом**, не сейчас | ✅ Не делаем |
| 6 | Настройки менюбордов («зрительные настройки») — вне скоупа | ✅ Не делаем |

### Целевой сценарий после переделки (коротко)

```mermaid
flowchart LR
    A[Открыли тему] --> B[Выбрали кампании у областей]
    B --> C{Нажали «глазик»}
    C --> D[Полный экран: видно рекламу как на менюборде]
    D --> E[Esc — вернулись к редактированию]
```

То есть после переделки пользователь сможет **одним нажатием увидеть результат** — как это будет выглядеть на настоящем менюборде.
