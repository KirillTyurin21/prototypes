# План переделки: элемент «Динамическая область» — финальное решение строго по DS-1121

> **Дата:** 2026-09-10
> **Статус:** ждёт одобрения Кирилла — после одобрения реализую.
> **Цель:** привести элемент «Динамическая область» к спецификации DS-1121 **без выдумок** — только то, что реально существует на стенде и описано в спеке.

## 1. Что изучено (последовательно)

1. **Спецификация DS-1121** (wiki, стр. 171154786) — источник правды: N динамических областей, мультивыбор Campaign в конструкторе, поиск, z-index ниже QR, раздел MenuBoard.
2. **Боевой стенд** `stand3-iikoweb`: раздел «Кампании» (медиапланы: название, период, время, дни недели, разрешения, режимы экрана, медиафайлы); «Настройка терминалов» (колонка «Кампании» — одиночный выбор на кассу); темы киоска (элемент «Рекламный блок» с ID `AdvertiseItemN`).
3. **Задача 8** (Михаил, 02.09) — «добавление компаний в рекламные блоки»; итоги встречи 08.09 (назначение внутри темы, превью «глазик», компания без страниц).
4. **Архитектурные договорённости** 14.07/08.07 — маппинги «элементы темы ↔ компании», дерево динамических объектов.
5. **Текущий прототип** `web-screens` — редактор `menuboard-theme-editor`.

## 2. Ключевые выводы (по фактам, без выдумок)

| Факт | Следствие |

## 3. Как выглядит финальный элемент (точно по DS-1121)

### 3.1 Инспектор «Динамической области»

```
Рекламные кампании          ← мультивыбор (чекбоксы)
├── [Поиск по названию]      ← живой фильтр (5.3-2)
├── Новогодняя (01.01.2026 - 31.01.2026)   ← формат строки (5.3-1)
├── Летнее меню (01.06.2026 - 31.08.2026)
├── ...
├── «Ничего не найдено»      ← если фильтр пуст (ошибка 8)
├── «Кампании не выбраны»    ← если ничего не отмечено
└── Выбрано кампаний: N      ← счётчик (5.3-1)

Макет                        ← 6.1: координаты, размеры, слой
├── Позиция X / Y
├── Ширина / Высота
├── Слой (z-index)           ← валидация: строго ниже слоя QR-кода (5.4)
├── Цвет фона / Прозрачность

Граница                      ← 6.1: цвет, толщина, скругление
```

**Убирается:** поле «Компания» (нет источника данных; в DS-1121 отсутствует).

### 3.2 Канвас

- Подпись области: **названия выбранных кампаний через запятую** (6.2).
- Если кампаний нет — подпись **«Динамическая область»** (6.2).
- Фон области: цвет + прозрачность (6.1).

### 3.3 Палитра и валидации (без изменений)

- Элемент «QR-код» в палитре — остаётся (нужен для правила слоёв).
- Кнопка «Динамическая область» всегда доступна (5.2-1).
- Блокировка сохранения: пустой `campaignIds` → «Выберите хотя бы одну рекламную кампанию» (ошибка 1).
- Блокировка сохранения: слой ≥ слоя QR → «Слой должен быть ниже слоя QR-кода» (ошибка 2).
- Пустой справочник кампаний → «Нет доступных кампаний. Создайте кампанию в разделе Кампании» (ошибка 3).

### 3.4 Миграция старых данных прототипа

- Панели старой модели → отдельные элементы (уже реализовано).
- `companyId` у старых элементов — **удаляется** (компании убираем).

2. **Полноэкранное превью («глазик»)** — одобрено на 08.09, но это фича конструктора в целом, не элемента; отдельной задачей.
3. **Фильтрация кампаний по компании** — снимается вместе с компаниями.
