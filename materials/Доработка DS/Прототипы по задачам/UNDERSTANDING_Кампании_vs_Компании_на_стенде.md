# Исследование: «Кампании» vs «Компании» — как устроено на стенде

> **Дата:** 2026-09-10
> **Стенд:** `stand3-iikoweb` (customer-screen, ver 9.6.4.367281)
> **Контекст:** проверка логики элемента «Динамическая область» прототипа `web-screens` (задача 8 «Мини-борды: компании в рекламные блоки», DS-1121)
> **Вопрос:** чем «Компании» отличаются от «Рекламных кампаний» и как это работает на самом деле

---

## 0. Главный приоритет

**Самое главное — чтобы редактор элемента «Динамическая область» в прототипе был верным.** Всё остальное (терминологические споры, справочники, бэкенд-маппинги) вторично. Каждый вывод и вариант ниже оценивается через один вопрос: «насколько это делает редактор „Динамической области“ корректным по фактам стенда и спецификациям (DS-1121 + задача 8)».

---

## 1. Что реально работает на стенде

### 1.1. Раздел «Кампании» (`#/campaign`)

**«Кампания» — это медиаплан.** Список кампаний (таблица): Название | Период действия | Время действия | Разрешение | Действия. Есть папки (группировка) и кампании.

Карточка кампании (форма «Редактирование кампании», `#/campaign/27`):

| Поле | Значение | Обязательное |
|---|---|---|
| Название кампании | текст | да |
| Дата начала / Дата окончания | даты | да |
| Время начала / Время окончания | время (00:00–23:59) | да |
| Дни недели | Пн–Вс (переключатели) | — |
| Разрешения | вкладки по разрешению (1024×768, «Добавить разрешение») | — |
| Режимы экрана (внутри разрешения) | «Экран заказа», «Экран оплаты», «Экран завершения», «Режим ожидания», «Касса не работает» | — |
| Медиафайлы (внутри режима) | «Добавить изображение или видео» | — |

Вывод: кампания отвечает на вопрос **ЧТО показывается** — медиафайлы с расписанием (период, время, дни недели) и привязкой к разрешению и режиму экрана.

### 1.2. Назначение кампаний на кассы (`#/arrivals-settings`)

Колонки таблицы терминалов: **Терминал | Тема | Терминальные группы | Кампании | Настройки**.

- «Кампании» — колонка с комбобоксом **одиночного выбора** («Выбрать» + clear) на каждый терминал.
- В селекте — список кампаний-медиапланов («1218», «1218 arrivals», «Новая кампания тест»…).
- На стенде есть кампания с названием «Компания Киоск» — просто неудачное имя кампании, добавляет терминологической путаницы.

Вывод: на стенде кампания назначается **на терминал (кассу)**, а не внутри темы. В MenuBoard по DS-1121 привязка переносится **в конструктор темы** (на элемент «Динамическая область»).

### 1.3. Киоск (`#/kiosk/terminals`, `#/kiosk/themes`)

- Настройка терминалов киоска: таблица «Киоск | Тема» + строка «Привязка по умолчанию: Выбрать» (комбобокс = выбор темы). Панелей/компаний в UI нет.
- В теме киоска элемент «Рекламный блок» (AdvertiseItemN) — заготовка без привязки контента; контент назначается в настройках терминалов.

### 1.4. Справочник «Компании»

**На стенде отсутствует.** «Компания» — внутренняя сущность DS из бэкенд-маппингов (договорённости 14.07): «связи элементов темы с компаниями». Компания = **рекламодатель/бренд**, чей контент показывается на панели.

## 2. Разница терминов

| | Кампания (Campaign) | Компания (Company) |
|---|---|---|
| Что это | Медиаплан: медиафайлы + период + время + дни + разрешения + режимы экрана | Рекламодатель/партнёр (бренд) |
| Где живёт | Реальный раздел «Кампании» на стенде | Маппинги тем на бэкенде (справочника в UI нет) |
| Как назначается | На терминал (стенд) / на динамическую область (MenuBoard, DS-1121) | На Advertise-панель внутри рекламного блока (задача 8) |
| Смысл | **ЧТО** показывается | **КТО** рекламируется |

Обе сущности нужны — это не дублирование: панель принадлежит компании, контент панели — кампании.

---

## 3. Редактор «Динамической области» — что верно, что нет

### 3.1. Проблема

В инспекторе «Динамической области» поля «Компания» и «Рекламные кампании» стоят рядом на одном уровне, без объяснения разницы — отсюда непонимание у команды/заказчика.

### 3.2. Что в редакторе уже ВЕРНО (сверено со стендом и спеками)

- Элемент — контейнер одной или нескольких Advertise-панелей (задача 8, ФТ-1)
- «Добавить панель», системные имена «Advertise панель N», удаление панели вместе с компанией и кампаниями, пустое состояние «Панели не добавлены» (ФТ-2)
- «Компания» — Select Single, одна на панель, можно сменить/снять (ФТ-3)
- «Рекламные кампании» — мультивыбор на панели: чекбоксы, формат «Название (ДД.ММ.ГГГГ - ДД.ММ.ГГГГ)», счётчик «Выбрано кампаний: N», пустое состояние «Кампании не выбраны» (ФТ-4, DS-1121 5.3)
- Живой поиск по названию + «Ничего не найдено»; сброс поиска при переключении панели/элемента (DS-1121 5.3-2)
- Минимум одна кампания на область обязательна — сохранение блокируется (DS-1121 5.3-4)
- Подпись на канвасе: «Advertise панель N: Компания — кампании»; без панелей — «Динамическая область» (ФТ-5 + DS-1121 6.2)
- Миграция старого формата: кампании без панелей → создаётся панель 1 с этими кампаниями (ФТ-6)
- Сохранение переживает перезагрузку страницы (ФТ-7)
- Слой (z-index) динамической области строго ниже слоя QR-кода + блокировка сохранения при нарушении (DS-1121 5.4)
- Настройки фона (цвет, прозрачность) и границы (DS-1121 6.1)

### 3.3. Что в редакторе требует правки (по варианту А)

- Нет объяснения разницы «Компания» vs «Кампании» — добавить подсказки под полями
- Названия полей однокоренные — развести: «Компания панели» / «Кампании панели»

## 4. Варианты решения

| # | Вариант | Суть | Оценка |
|---|---|---|---|
| А | Оставить обе, навести порядок | Иерархия «панель → компания → кампании»; подсказки под полями («Компания — рекламодатель, чей контент показывает панель», «Кампании — медиаплан с расписанием из раздела Кампании»); названия развести («Компания панели» / «Кампании панели») | ✅ Рекомендуется |
| Б | Убрать компании | На стенде их нет, DS-1121 не требует | ⚠️ Противоречит поручению Михаила (задача 8) |
| В | Компания фильтрует список кампаний | Показывать кампании выбранной компании | ⚠️ На стенде у кампаний нет владельца-компании; открытый вопрос к Мише |

**Рекомендация:** вариант А — правки **только в редакторе «Динамической области»** (подсказки под полями + уточнённые названия «Компания панели» / «Кампании панели»). Вся уже верная логика (панели, мультивыбор, поиск, валидации, слой, миграция) не меняется. Открытый вопрос к Мише: «принадлежат ли кампании компаниям (нужна ли фильтрация списка кампаний по выбранной компании)».
