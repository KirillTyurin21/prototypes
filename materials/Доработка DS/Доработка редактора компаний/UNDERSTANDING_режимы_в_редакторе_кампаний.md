## 1. Суть доработки

В **редакторе кампаний** сейчас есть 4 фиксированные вкладки режимов экрана:
«Экран заказа», «Экран оплаты», «Экран завершения», «Режим ожидания».

Михаил хочет:
1. **По умолчанию показывать всегда только 2 вкладки** — «Экран заказа» и «Режим ожидания» (общие режимы для Экрана покупателя и Электронной очереди).
2. Третьей вкладкой — кнопку **«+»** («Добавить экран»).
3. При нажатии на «+» — **селектор выбора режима** с двумя группами:
   - **Стандартные**: «Экран оплаты», «Экран завершения», «Касса не работает» (режимы Экрана покупателя, используются редко; «Касса не работает» на фактическом сайте ещё не добавлена, но включаем);
   - **Кастомные**: режимы, которые пользователь **сам создал** в редакторе темы Электронной очереди (через «Добавить» в селекторе режимов темы).
4. После выбора режима — новая вкладка **появляется на месте вкладки «+»**, а сам «+» **смещается вправо** и становится соседней вкладкой. Пункт **исчезает из селектора** (выбранное нельзя выбрать дважды).
5. Так можно добавлять режимы **сколько угодно раз**, пока не выбраны все доступные режимы. Когда все режимы добавлены — вкладка **«+» исчезает**.
6. У добавленного режима на вкладке есть **крестик удаления**: после удаления режим возвращается в селектор, а вкладка **«+» снова появляется** (или «+» появится, если пользователь создаст новый кастомный режим в теме).
7. Контент выбранного режима — **та же зона редактирования**, что и у обычных вкладок (изображения/видео с длительностью, как в текущем прототипе).

## 4. Целевое состояние (to-be)

### 4.1. Вкладки режимов в редакторе кампаний

| # | Вкладка | Источник | Поведение |
|---|---------|----------|-----------|
| 1 | «Экран заказа» | Общий (ЭС + ЭО) | Всегда видима, не удаляется |
| 2 | «Режим ожидания» | Общий (ЭС + ЭО) | Всегда видима, не удаляется |
| 3…N | Добавленные режимы | «Стандартные» или «Кастомные» | Появляются после выбора из «+» — **встают на место «+», сдвигая его вправо**; на вкладке есть **крестик удаления** |
| N+1 | **«+»** (Добавить экран) | — | Открывает селектор выбора режима; **исчезает, когда выбраны все доступные режимы**; появляется снова после удаления режима или создания нового кастомного режима в теме |

- «+» — всегда последняя вкладка: при добавлении нового режима вкладка встаёт **на место «+»**, а «+» смещается вправо.
- Порядок вкладок после добавлений: `Экран заказа | Режим ожидания | <добавленные режимы> | +`.
- Выбранные режимы **исчезают** из селектора (нельзя добавить дважды).
- Когда все доступные режимы добавлены — вкладка **«+» исчезает** (селектор больше не нужен).
- Удаление добавленного режима — **крестик на вкладке**: режим возвращается в селектор, «+» **появляется снова**.
- Если «+» скрыт (все режимы выбраны), он появится снова, когда пользователь создаст новый кастомный режим в теме ЭО.

### 4.2. Селектор выбора режима (открывается из «+»)

Дропдаун (по образцу селектора «Настройка режима» в редакторах тем):

```
СТАНДАРТНЫЕ
  Экран оплаты (ID)
  Экран завершения (ID)
  Касса не работает (ID)
КАСТОМНЫЕ
  <Имя кастомного режима 1> (A1)
  <Имя кастомного режима 2> (A2)
```

- Рядом с именем режима показывается **ID** (например, «Режим доставки (A1)») — подтверждено 13.08.2026.
- Группа «Кастомные» показывается только если в темах ЭО есть созданные пользователем режимы.
- Если все режимы уже добавлены — вкладка **«+» исчезает** (селектор открыть нельзя).

### 4.3. Отображение режима в кампании

- После выбора: обычная вкладка с **названием режима** + та же зона редактирования (медиа + канвас), что у «Экран заказа».
- Добавленные режимы живут внутри **разрешения** (как сейчас живут 4 режима).
- У вкладки добавленного режима — **крестик удаления** (у общих режимов «Экран заказа» и «Режим ожидания» крестика нет).

## 5. Ключевые концепции

1. **Режим = экран**, для которого настраивается реклама кампании (Экран заказа, Экран оплаты, …).
2. **Общие режимы** («Экран заказа», «Режим ожидания») — есть в обеих темах (ЭС и ЭО), всегда видимы.
3. **Стандартные режимы** («Экран оплаты», «Экран завершения») — только у ЭС, редкие, скрыты за «+».
4. **Кастомные режимы** — создаются только в теме ЭО («Добавить» в селекторе режима); имеют имя + ControlArea-условия; добавляются в кампанию через «+».
5. **Связка по ID** — режим в кампании ссылается на ID режима темы; плагин по ID определяет, на каком экране показывать рекламу. ID пользователю не показывается (или показывается как справочная информация), задавать вручную не нужно.
6. **Кампания не типизирована** — одна кампания может использоваться и для ЭС, и для ЭО.
7. **Контент режима** — набор изображений/видео с длительностью (текущая механика прототипа сохраняется).

## 6. Ограничения системы

| # | Ограничение | Следствие |
|---|-------------|-----------|
| О-1 | Кастомные режимы создаются **только** в теме Электронной очереди (в ЭС нет «Добавить») | В селекторе «+» группа «Кастомные» наполняется только из тем ЭО |
| О-2 | Режимы ЭС фиксированы (4 шт.), их нельзя ни создать, ни удалить | Группа «Стандартные» в селекторе — константа |
| О-3 | «Экран заказа» и «Режим ожидания» — общие для обеих тем | Они не могут быть ни скрыты, ни удалены из редактора кампаний |
| О-4 | Связка кампания↔режим — по ID, имена режимов могут совпадать/переименовываться | Выбор в селекторе должен показывать имя, но хранить ID |
| О-5 | Пользователь создаёт кастомный режим с условиями ControlArea (`>`, `<`, `==`, `>=`, `<=`, `!=` + значение + OR/AND) | Кастомный режим в кампании — это тот же экран с фильтром; в кампании фильтр не редактируется (он из темы) |
| О-6 | Выбранный режим нельзя добавить дважды (один экран — одна настройка) | Выбранные пункты исчезают из селектора |
| О-7 | Редактор кампаний в прототипе — «песочница» с мок-данными | Кастомные режимы для прототипа берём из мок-данных тем ЭО |
| О-8 | Добавленный режим можно удалить из кампании (крестик на вкладке) | После удаления режим возвращается в селектор, «+» появляется снова |

## 7. Сценарии использования

### Сценарий 1: Новая кампания для всех экранов
1. Пользователь создаёт кампанию, добавляет разрешение.
2. По умолчанию видит вкладки «Экран заказа» и «Режим ожидания» — настраивает медиа.
3. Нажимает «+» → селектор → «Стандартные → Экран оплаты» → вкладка «Экран оплаты» встаёт **на место «+»**, «+» сдвигается вправо.
4. Нажимает «+» → селектор → «Кастомные → Режим доставки» → вкладка встаёт на место «+», «+» снова сдвигается вправо.
5. В селекторе остались только недобавленные режимы.
6. Когда все доступные режимы добавлены — вкладка «+» **исчезает**.

### Сценарий 2: Кастомный режим создан в теме ЭО
1. В теме ЭО: «Настройка режима» → «Добавить» → режим «Режим доставки» (ControlArea: `>` 8).
2. В кампании «+» → «Кастомные» виден «Режим доставки».
3. Пользователь добавляет его — вкладка появляется, настраивается медиа.
4. Плагин по ID режима показывает рекламу кампании на экране «Режим доставки».

### Сценарий 3: Удаление добавленного режима
1. Пользователь нажимает **крестик на вкладке** добавленного режима.
2. Вкладка удаляется, режим возвращается в селектор «+» (снова доступен для добавления).
3. Если «+» был скрыт (все режимы были выбраны) — он **снова появляется**.

### Сценарий 4: Новый кастомный режим появился в теме
1. Все режимы кампании добавлены, вкладка «+» скрыта.
2. Пользователь в теме ЭО создаёт новый кастомный режим «Экран доставки» (ID A3).
3. В кампании снова появляется вкладка «+», в селекторе «Кастомные» — новый режим.

### 8.1. Структура данных режимов (предложение для прототипа)

```typescript
type ScreenModeKind = 'common' | 'standard' | 'custom';

interface ScreenModeInfo {
  id: string;            // 'order', 'idle', 'payment', 'finish', 'not-working', 'a1', ...
  name: string;          // 'Экран заказа', ...
  kind: ScreenModeKind;
  // для кастомных — условия показа из темы ЭО:
  controlArea?: { operator: string; value: number; combine?: 'OR' | 'AND' }[];
}
```

- `common` («Экран заказа», «Режим ожидания») — всегда вкладки, без крестика удаления.
- `standard` («Экран оплаты», «Экран завершения», «Касса не работает») — группа «Стандартные» в селекторе.
- `custom` — группа «Кастомные» в селекторе.
- Разрешение кампании хранит `modes: Record<string, CampaignMedia[]>` (ключ — ID режима) вместо фиксированного `Record<ScreenModeKey, CampaignMedia[]>`.

### 8.2. UI селектора «+»

- Вкладка «+» (иконка plus) последней в ряду горизонтальных вкладок.
- Клик → дропдаун под вкладкой (как у селектора «Настройка режима» в темах): строки-опции 48px; заголовки групп «Стандартные»/«Кастомные» (серые, как лейблы групп).
- Строка опции: **имя режима + ID в скобках** (например, «Экран оплаты (2)», «Режим доставки (A1)»).
- Выбор → вкладка добавляется (встаёт на место «+»), режим уходит из селектора.
- Крестик на вкладке добавленного режима → удаление: режим возвращается в селектор, «+» появляется снова.
