# ПОНИМАНИЕ ЗАДАЧИ: Прокрутка вкладок режимов в редакторе кампаний

*Создано: 13.08.2026*
*Контекст: продолжение задачи «Режимы экранов в редакторе кампаний» (см. `UNDERSTANDING_режимы_в_редакторе_кампаний.md`)*
*Источник: уточнение Михаила от 13.08.2026*

---

## 1. Проблема

В редакторе кампаний ряд горизонтальных вкладок режимов может содержать до **8 вкладок**:
2 общих («Экран заказа», «Режим ожидания») + до 5 добавляемых («Экран оплаты», «Экран завершения», «Касса не работает», кастомные A1, A2) + вкладка «+».

Сейчас вкладки растянуты на всю ширину ряда (`flex: 1`). При большом количестве вкладок они **сжимаются по ширине** — названия режимов («Экран завершения», «Касса не работает») перестают помещаться, текст обрезается/переносится.

**Требование:** вкладки не должны сжиматься ниже своего минимального размера. Когда ряд переполнен — появляются **кнопки-стрелки прокрутки** слева и справа, которые прокручивают ряд вкладок.

---

## 2. Целевое поведение

1. Каждая вкладка режима имеет **минимальную ширину** (~160px) и не сжимается меньше неё.
2. Вкладка **«+»** — фиксированная (56px), всегда видима, прижата к правому краю, **не прокручивается** (она должна быть доступна всегда).
3. Когда все вкладки помещаются — стрелок нет (текущее поведение).
4. Когда ряд переполнен — появляются стрелки:
   - **Правая стрелка** — если справа есть скрытые вкладки.
   - **Левая стрелка** — если ряд прокручен вправо (есть скрытое слева).
   - Обе стрелки могут быть видны одновременно, если ряд прокручен «в середине».
5. Клик по стрелке прокручивает ряд на шаг (~200px, плавно, `behavior: smooth`).
6. При переключении на вкладку, которая вне зоны видимости, ряд **автоматически прокручивается** так, чтобы активная вкладка была видна.
7. При изменении ширины окна состояние стрелок **пересчитывается**.
8. Селектор выбора режима («+») продолжает открываться под вкладкой «+».

---

## 3. Решение (аналог Material Tab Header Pagination)

Ориентир — поведение пагинации вкладок Angular Material (`mat-tab-header-pagination`): стрелки стоят по краям заголовка, между ними — прокручиваемый список вкладок.

### 3.1. Новая структура ряда вкладок

```
<div class="htabs-wrap">
  <div class="htabs">
    [← стрелка, если есть скрытое слева]
    <div class="htabs-scroll">          ← зона прокрутки (overflow-x: hidden/auto)
      <button class="htab">Экран заказа</button>
      <button class="htab">Режим ожидания</button>
      <button class="htab">Экран оплаты ×</button>
      ...
    </div>
    [→ стрелка, если есть скрытое справа]
    <button class="htab htab-plus">+</button>   ← фиксирован, не скроллится
  </div>
  <div class="mode-selector">...</div>  ← без изменений
</div>
```

### 3.2. Логика видимости стрелок

- Компонент хранит `tabScrollLeft` и флаги `canScrollLeft`, `canScrollRight`.
- Пересчёт в обработчике `(scroll)` зоны прокрутки и при изменении списка вкладок:
  - `canScrollLeft = scrollLeft > 0`
  - `canScrollRight = scrollLeft + clientWidth < scrollWidth`
- Прокрутка: метод `scrollTabs(direction)` → `scrollBy({ left: ±200, behavior: 'smooth' })`.
- Автопрокрутка к активной вкладке: при `addMode()` / клике на вкладку — `el.scrollIntoView({ block: 'nearest', inline: 'nearest', behavior: 'smooth' })` (через `ElementRef`/поиск по индексу, без `querySelector` по DOM — Angular-способ: `*ngFor` + `ViewChildren` или ссылка `#tabEl`).
- Пересчёт при `window.resize` (через `HostListener`).

### 3.3. Стили

| Элемент | Стиль |
|---|---|
| `.htab` (вкладка режима) | `flex: 0 0 auto; min-width: 160px;` (вместо `flex: 1`) |
| `.htab-plus` | `flex: 0 0 56px;` — фиксирована, вне зоны прокрутки |
| `.htabs-scroll` | `flex: 1; display: flex; overflow-x: auto; scrollbar-width: none;` (скроллбар скрыт) + `::-webkit-scrollbar { display: none; }` |
| `.htab-pagination` (стрелки) | ширина ~40px, высота 48px (как вкладка), иконки chevron-left/right 20px, цвет `rgba(0,0,0,0.54)`, hover `#448aff` + фон `rgba(0,0,0,0.04)`, border-bottom как у вкладок (`1px solid #e0e0e0`) |
| `.htab-pagination-disabled` | скрыта (не рендерится через `*ngIf`) |

### 3.4. Поведение при удалении/добавлении вкладок

- При добавлении режима (`addMode`) и удалении (`removeModeTab`) список вкладок меняется → флаги стрелок пересчитываются автоматически (через `ngAfterViewChecked` + проверку `scrollWidth` или вручную после мутации + `setTimeout`).
- Если после удаления все вкладки помещаются — обе стрелки исчезают.

## 5. Проверочные сценарии

1. **Нет переполнения** (2 общие + «+») — стрелок нет, вид как сейчас.
2. **Переполнение** — добавить все 5 режимов (7 вкладок + «+»): появляется правая стрелка, вкладки не сжимаются ниже 160px.
3. **Прокрутка вправо до конца** — правая стрелка исчезает, левая появляется.
4. **Прокрутка в середине** — видны обе стрелки.
5. **Клик по стрелке** — плавная прокрутка на ~200px.
6. **Активная вкладка вне зоны видимости** — переключение режима автоскроллит её в зону.
7. **«+» всегда видим** — при любой прокрутке остаётся на правом краю.
8. **Удаление вкладок** — после удаления всех лишних стрелки исчезают.
9. **Изменение ширины окна** — стрелки пересчитываются (сужение → появляются, расширение → исчезают).
10. **Селектор «+»** — открывается и работает как раньше.
