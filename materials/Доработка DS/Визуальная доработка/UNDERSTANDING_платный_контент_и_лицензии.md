## 1. Суть доработки

В редакторе тем появляется **платный контент** - элементы темы, доступные только при наличии **платной лицензии**. Сейчас такие элементы (например, "Область подсказок" / hints) доступны всем без ограничений.

**Задача:** ввести механизм лицензирования платных элементов темы:
1. Скрывать платные элементы в палитре, если лицензии нет
2. Подсвечивать платные элементы (значок "!" + тултип "доступен при платной лицензии")
3. Показывать **нескрываемый, но ненавязчивый баннер** на экране/предпросмотре, если тема содержит платный элемент, а лицензии нет
4. **НЕ запрещать** добавлять/редактировать/копировать платные элементы - только информировать
5. Платный элемент **всегда платный** - его нельзя сделать бесплатным

## 2. Ключевые правила лицензирования (из встречи)

### 2.1. Лицензия проверяется по всей сети (Михаил, 02:16)

> "Мы наши продукты по РМС не делим. Мы делим только по наличию лицензии. Если есть хоть где-то лицензия - всё, человек может эту тему создавать уже платную смело."

- **Нет разделения по организациям/РМС** - лицензия глобальная для сети
- Если **хотя бы на одном РМС** куплена платная лицензия -> платные элементы доступны
- Пользователь может создать платную тему, даже если лицензия есть только на одном РМС

### 2.2. Поведение в редакторе (Михаил, 04:27)

> "В редакторе не запрещаем [добавлять платные элементы]. Но на экране будет баннер, что у вас нет платной лицензии."

- **В редакторе** - НЕ блокируем добавление/редактирование/копирование платных элементов
- **На экране** (в плагине) - показываем баннер, если тема с платным элементом назначена на терминал

### 2.3. Копирование темы - не обход (Михаил, 03:41-47)

> "Копирую тебе, никто не запрещает это делать. [...] она будет подсвечена, что она содержит платный контент."

- Копирование темы с платным элементом **не запрещается**
- Скопированная тема **подсвечивается** как содержащая платный контент

### 2.4. Распространение (Михаил, 06:45)

> "Это везде" (Customer Screen, Rivals, Kasta, MerciCoin; киоск - пока не ясно)

- Механизм применяется **ко всем типам экранов**
- **Киоск** - пока не определено (открытый вопрос)

### 2.5. Платный элемент всегда платный (Михаил, 06:54)

> "Там только сам по себе, наверное, платный будет. Он вообще бесплатный не будет."

- Платный элемент **не может стать бесплатным** - он всегда платный
- Нет механизма «сделать элемент бесплатным» - это не предусмотрено
- В прототипе: платный элемент помечается `isPremium: true` навсегда, без возможности снять флаг

### 2.6. Баннер ненавязчивый (Михаил, 06:29)

> "В принципе, она так не мешает. Как винда. Без лицензии."

- Баннер **не мешает работе** пользователя - ненавязчивый, не блокирует действия
- Не перекрывает контент, не требует действий для закрытия (нескрываемый, но и не мешающий)
- Располагается так, чтобы не мешать редактированию темы

### 3.2. Ключевой факт: палитра элементов - общий компонент

**`ElementPaletteComponent`** используется во **всех редакторах тем** (CS, Kiosk, Menuboard, Arrivals):

| Редактор | Как передаёт категории |
|----------|----------------------|
| CS (`theme-editor-screen`) | `[categories]="themeCategories"` - из `CS_THEME_CATEGORIES` |
| Kiosk (`kiosk-theme-editor-screen`) | `[categories]="themeCategories"` - из `KIOSK_THEME_CATEGORIES` |
| Menuboard (`menuboard-theme-editor-screen`) | `[categories]="themeCategories"` - из `MENUBOARD_THEME_CATEGORIES` |
| **Arrivals (`arrivals-theme-editor-screen`)** | `[categories]="themeCategories"` - из `ARRIVALS_THEME_CATEGORIES` |

Это значит: **модификация палитры автоматически затронет все редакторы**. Достаточно добавить `@Input() hasPremiumLicense` и логику скрытия/подсветки в одном месте.

### 3.3. Категории элементов в каждом редакторе

| Редактор | Источник категорий | Кол-во элементов | Платный элемент |
|----------|--------------------|------------------|-----------------|
| CS | `CS_THEME_CATEGORIES` | 31 | `hints` - "Область подсказок" (верхнеуровневый тип из `THEME_ELEMENT_TYPES`) |
| Kiosk | `KIOSK_THEME_CATEGORIES` | 11 | `kiosk-hints-area` - "Область подсказок" |
| Menuboard | `MENUBOARD_THEME_CATEGORIES` | 7 | `area` - "Область контролов" (требует уточнения) |
| **Arrivals (Электронная очередь)** | `ARRIVALS_THEME_CATEGORIES` | 8 | **`area` - "Область"** (категория «Контейнеры») |

**Важный нюанс CS редактора:** "Область подсказок" (hints) - это **верхнеуровневый тип** из `THEME_ELEMENT_TYPES` (5 элементов: image, text, advertise, animation, hints), а не элемент из `CS_THEME_CATEGORIES` (31 элемент). Палитра показывает категории (`CS_THEME_CATEGORIES`), но `addElementFromPalette` ищет тип в `elementTypeOptions` (построенном из `THEME_ELEMENT_TYPES`). Это значит:
- В палитре нужно пометить элемент `hints` в `CS_THEME_CATEGORIES` (если он там есть) **ИЛИ** добавить `hints` в категории палитры
- В `THEME_ELEMENT_TYPES` - пометить `{ type: 'hints', ..., isPremium: true }`

### 4.2. Детализация каждого варианта

#### Вариант A - Платный элемент скрыт (нет лицензии)

- **Условие:** `!hasPremiumLicense` И элемент имеет `isPremium: true`
- **Где:** палитра элементов (`ElementPaletteComponent`)
- **Реализация:** фильтрация `cat.elements` - исключить элементы с `isPremium: true`
- **Пустые категории** (все элементы скрыты) - тоже скрыть
- **Цитата (03:20):** "Но ты его вообще не увидишь, да?"

#### Вариант B - Платный элемент подсвечен (есть лицензия)

- **Условие:** `hasPremiumLicense` И элемент имеет `isPremium: true`
- **Где:** палитра элементов (`ElementPaletteComponent`)
- **Реализация:** иконка `alert-circle` (размер 14px) справа от названия элемента
- **Тултип:** "Доступен при платной лицензии" (через HTML-атрибут `title`)
- **Цитата (01:12):** "вот эта точка с восклицательным знаком, да, при наведении на него, ну, подсветите, какой лицензии он принадлежит"

#### Вариант C - Тема с платным контентом в списке

- **Условие:** тема содержит хотя бы один элемент с `isPremium: true`
- **Где:** таблица тем - ячейка `name` (рядом с названием)
- **Реализация:** значок `alert-circle` (14px, цвет `app-accent` - оранжевый) после названия
- **Тултип при наведении:** список названий платных элементов, например:
  "Платный контент: Область подсказок"
- **Цитата (03:47):** "она будет подсвечена, что она содержит платный контент. [...] список этих элементов платных"

#### Вариант D - Баннер в предпросмотре редактора

- **Условие:** `!hasPremiumLicense` И тема содержит платный элемент
- **Где:** canvas/preview в редакторе темы (левая колонка)
- **Реализация:** полоса в верхней части canvas (под верхней панелью/тулбаром)
  - Фон: оранжевый/предупреждающий (напр. `#FFF3E0` с бордером `#FF6D00`)
  - Текст: "У вас нет платной лицензии. Элемент "Область подсказок" будет недоступен на экране."
  - Иконка: `alert-triangle`
  - **Без кнопки закрытия** (нескрываемый)
  - **Ненавязчивый** - не мешает работе, не перекрывает canvas (Михаил, 06:29)
- **Цитата (04:48-55):** "Будет нескрываемый баннер. [...] Должен увидеть [на предпросмотре]"

#### Вариант E - Сообщение при добавлении платного элемента

- **Условие:** `!hasPremiumLicense` И пользователь добавил платный элемент
- **Где:** редактор темы - toast/уведомление
- **Реализация:** использовать существующий механизм toast в редакторе

## 5. Как модифицировать каждый компонент

### 5.1. Типы данных (`cs-types.ts`)

**Добавить в интерфейс `ThemeElementTypeOption`:**
```typescript
export interface ThemeElementTypeOption {
  type: string;

/** Проверка: является ли тип элемента платным */
isPremiumElementType(type: string): boolean {
  const opt = THEME_ELEMENT_TYPES.find(t => t.type === type);
  return opt?.isPremium ?? false;
}

/** Проверка: содержит ли тема платные элементы */
themeHasPremiumElements(theme: CSTheme): boolean {
  return theme.elements.some(e => this.isPremiumElementType(e.type));
}

/** Получить список названий платных элементов в теме */
getPremiumElementNames(theme: CSTheme): string {
  return theme.elements
    .filter(e => this.isPremiumElementType(e.type))
    .map(e => e.name)
    .join(', ');
}
```

## 6. Вопросы, которые я задал себе, и ответы

### 6.1. Какие элементы считать платными?

**Ответ:** На встрече явно упоминалась только "Область подсказок" (hints). Это единственный подтверждённый платный элемент. Полный список платных элементов нужно уточнить у Михаила. В прототипе для демонстрации достаточно пометить `hints` (CS), `kiosk-hints-area` (Kiosk), `area` (Menuboard - под вопросом), **`area` (Arrivals - "Область", подтверждено Кириллом как главный пример)**.

### 6.2. Что происходит, если пользователь удалит платный элемент, а потом захочет добавить заново?

**Ответ (Михаил, 02:16):**
- Если лицензии нет - элемент не увидит в палитре (вариант A)
- Если лицензия есть - сможет добавить (вариант B)
- Удаление не блокируется

### 6.3. Можно ли обойти систему, скопировав тему с платным элементом?

**Ответ (Михаил, 03:41-47):**
- Копирование **не запрещается**
- Скопированная тема **подсвечивается** как содержащая платный контент (вариант C)
- Это не обход - система информирует, но не блокирует

### 6.4. Блокируется ли назначение платной темы на терминал?

**Ответ (Михаил, 04:47):** Нет. "Мы и не запрещаем выбирать эту тему, назначать на терминал." На экране будет баннер (вариант F).

### 6.5. Виден ли баннер в предпросмотре редактора?

**Ответ (Михаил, 04:55):** Да. "Должен увидеть [баннер на предпросмотре]." Баннер появляется, как только платный элемент добавлен в тему (вариант D).

### 6.6. Баннер нескрываемый - что это значит?

**Ответ (Михаил, 04:48):** Баннер нельзя закрыть (нет кнопки "x"). Он постоянно виден, пока тема содержит платный элемент без лицензии. Это отличает его от обычных информационных баннеров, которые можно закрыть.

**Дополнение (Михаил, 06:29):** "В принципе, она так не мешает. Как винда. Без лицензии." Баннер **ненавязчивый** - не мешает работе, не перекрывает контент, не требует действий. Нескрываемый, но и не мешающий.

### 6.7. Распространяется ли на киоск?

**Ответ (Михаил, 06:48):** "Пока не знаю." Открытый вопрос. В прототипе имеет смысл применить ко всем редакторам (включая Kiosk) для единообразия, но отметить в changelog как "требует уточнения".

### 6.8. Как хранить состояние лицензии в прототипе?

**Ответ:** В `CsDataService` как `hasPremiumLicense: boolean` (мок). Значение по умолчанию - `true` (лицензия есть), чтобы прототип по умолчанию показывал полный функционал. Для демонстрации обоих состояний - переключатель.

### 6.9. Нужно ли показывать платный элемент в палитре, если лицензии нет?

**Ответ (Михаил, 03:20):** "Ты его вообще не увидишь." Элемент **скрыт полностью**. НЕ показывать заблокированным/засеренным. Это явное указание Михаила.

### 6.10. Что с уже существующими темами, где платный элемент добавлен до изменений?

**Ответ (Михаил, 02:05):** "Ничего, пусть будет." Пользователь может редактировать, менять, удалять. Тема просто подсвечивается как содержащая платный контент (вариант C).

### 6.11. Как определить, что тема содержит платный элемент?

**Ответ:** По типу элемента. `CsDataService.isPremiumElementType(type)` проверяет, помечен ли тип как `isPremium: true` в `THEME_ELEMENT_TYPES`. Вычислять динамически - не хранить флаг в данных темы.

### 6.12. Нужно ли показывать баннер в списке тем?

**Ответ:** Нет. В списке тем - только метка "платный контент" (вариант C). Баннер - только в редакторе (вариант D) и на экране (вариант F).

### 6.13. Что делать с категориями палитры, которые становятся пустыми?

**Ответ:** Скрыть пустые категории. Если все элементы в категории платные и скрыты (нет лицензии) - категория не отображается.

### 6.14. Как отличить платный элемент от бесплатного в данных?

**Ответ:** Только по типу. В существующих темах 1 и 2 уже есть элемент `hints` - после изменений они будут считаться содержащими платный контент. Это правильное поведение.

### 6.15. Кто отвечает за демонстрацию переключения лицензии?

**Ответ:** В прототипе - аналитик (Кирилл). Нужно добавить UI-переключатель для демонстрации обоих состояний (с лицензией / без лицензии). Расположение - в шапке прототипа или на странице тем.

### 6.16. Можно ли сделать платный элемент бесплатным?

**Ответ (Михаил, 06:54):** "Он вообще бесплатный не будет." Платный элемент **всегда платный** - нет механизма снять платность. В прототипе: `isPremium: true` фиксируется навсегда, без возможности изменить.
