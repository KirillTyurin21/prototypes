## 9. Технические детали

### Использование в коде (Angular)

```typescript
// Импорт модуля
import { RestoIconsModule } from '@resto/icons';

// В компоненте
imports: [..., RestoIconsModule],

// В шаблоне:
// Категория:
<mat-icon [svgIcon]="'resto-menu:constructor'"></mat-icon>

// Элемент:
<mat-icon [svgIcon]="'resto:edit_document'"></mat-icon>
```

### Формат данных (TypeScript)

```typescript
interface ElementItem {
  type: string;
  label: string;
  icon: string;  // Например: 'resto:edit_document' или 'resto-menu:external-orders'
}

interface ElementCategory {
  id: string;
  label: string;
  icon: string;  // Например: 'resto-menu:constructor'
  collapsed: boolean;
  elements: ElementItem[];
}
```

### Правила

1. **Категории** всегда используют `resto-menu` namespace, элементы — либо `resto`, либо `resto-menu`
2. **Одна и та же иконка** может использоваться в разных продуктах для одинаковых по смыслу элементов
3. **При отсутствии подходящей иконки** — использовать иконку категории как fallback
4. **Новые иконки** добавляются через процедуру: положить SVG в `server/web/inter-app-assets/icons` → добавить в `libs/icons/examples/default/icons-list.ts`
